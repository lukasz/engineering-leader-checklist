# Capacity Planning

[The Engineering Leader’s Checklist](../../README.md) -> [Delivery 🚚](../delivery.md)

### Checklist
- Holidays 
  - Annual Leave
  - Parental Leave
  - Bank Holidays
  - … and any other group or individual day off! (training days, offsites etc.) 
- % of available dev time based on availability per week/sprint/quarter
- if using any metric for estimating the size of tasks (e.g. Story Points) - keep track and use it to estimate how the capacity for the upcoming period translates to the amount of work the team can handle (accounting for BAU/KTLO)
