# Metrics 📏

[The Engineering Leader’s Checklist](../README.md)

Description 

## Checklist
- **Delivery** - how well do you progress against your goals? e.g. throughput, sprint velocity etc. 
- **Churn** - how much work needs to be discarded? e.g. % of tasks cancelled
- **Tech Debt** - how deep is your tech debt? 
- **Security** - how secure is your system/product? e.g. against OWASP, ISO 27001, etc. 
- DORA / SPACE / DevEx
- **Health checks**
  - Product metrics
  - Observability
